# KMJG-Website

Project ini adalah website Next.js untuk KMJG. Berisi halaman katalog, chatbot sederhana, dan data produk/pengetahuan.

## Cara Menjalankan (lokal)

Instal dependensi lalu jalankan server development:

```bash
npm install
npm run dev
```

Buka http://localhost:3000 untuk melihat halaman.

## Struktur Singkat

- `src/app` - entry aplikasi dan halaman
- `src/components` - komponen UI (mis. `Chatbot`)
- `src/data` - data produk dan knowledge base

## Deploy
Direkomendasikan menggunakan Vercel untuk deploy Next.js.
